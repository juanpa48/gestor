1. **NO PUEDES** saltarte fases ni hacer todo al mismo tiempo. Trabajarás exclusivamente en una fase a la vez.
2. **NO PUEDES** avanzar a la siguiente fase hasta que yo te diga explícitamente "Procede con la siguiente fase".
3. Debes usar un archivo `task.md` en la raíz para ir marcando con `[x]` las tareas que vayas completando, de modo que ni tú ni yo perdamos el hilo.

1. Lee detenidamente el archivo `docs/MIGRATION_GUIDE.md` para entender todo el contexto, el inventario actual, el esquema SQL (Fase 2), los endpoints (Fase 3), la refactorización frontend (Fase 4) y el despliegue (Fase 5).

3. Analiza el `task.md` existente (o crea uno nuevo `task_migration.md`) basándote en las fases del `MIGRATION_GUIDE.md` para que podamos llevar el control de la ejecución del código.
4. Cuando termines de leer todo, dame un resumen de 3 líneas confirmando que entendiste, dime qué herramienta o comando vas a usar para crear la base de datos, y **ESPERA** a que yo te dé la orden de iniciar a ejecutar la Fase 2 (Creación de BD).
